> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every alert and document in the Release layer describes the system as it runs, one test states the layer's surface, and the layer's rules each have a test proven to fail when the rule breaks.

**Architecture:** No behavior change. One alert string, documentation, two new architecture tests, and a mutation pass. Runs after Part 2 has merged, so the edge test and the grant rule include Part 2's check.

**Tech Stack:** Python 3.14, pytest, Markdown.

**Spec:** `docs/superpowers/specs/2026-11-03-release-layer-design.md` (Parts 1, 3, 4, 5; Non-goals).

## Global Constraints

- No new alert, no new lane, no deleted code: the exit manifests attest the tracker adapter, the reconciliation passes, `consistency-check`, `in-flight-units`, and `dead-letter`.
- Don't bound `GET /api/v1/observations`, widen `test_release_routes_call_no_mutator.py`, or add a User-Agent to `attest_exit_criteria.py` (spec Non-goals).
- Superseded text moves to the ADR or `docs/history/claude-md-invariants-archive.md` that superseded it; nothing is deleted outright.
- Docs follow the repository's existing style: present tense, no "currently" or "new".
- Work in `.worktrees/release-p3` with its own venv and database `orchestrator_test_release_p3`. Never touch the main tree.

## Review Focus

1. A doc correction that states a new falsehood: each corrected sentence must be checked against code, with the file and line in the commit message (Task 2).
2. The edge test passing against a route table that lacks a route `image-release` needs (Task 3's control test).
3. A rule test that still passes with the rule broken: the mutation pass reports every survivor (Task 4).
4. An alert that names a command or page that doesn't exist (Task 1's test reads the named path).
5. The attest "home" statement contradicting the workflow's own header comment (Task 2).
