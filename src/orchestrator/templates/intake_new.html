Package intake is a human gate, and human gates are browser-only by design (ADR-0006). This form is the production path: the equivalent API route requires a human actor but is machine-only at the proxy, and no standing human credential exists.

Paste the intake payload

Generate it with orchestrator emit-intake-payload against the approved package, then paste the output verbatim. It is validated exactly as the API route validates it — the package must be approved, its content hash must match its lineage approval, and the payload must be CLI-verified. Nothing here relaxes those checks.
